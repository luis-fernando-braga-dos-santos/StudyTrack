# StudyTrack 📚

## Sobre o projeto

O **StudyTrack** é um gerenciador de estudos desenvolvido para ajudar estudantes de escolas a organizar sua rotina escolar de maneira simples e prática.

O sistema permite que os alunos cadastrem suas matérias, organizem suas atividades e acompanhem quais tarefas já foram concluídas, facilitando o planejamento e a organização dos estudos.

## Objetivo

O principal objetivo do StudyTrack é auxiliar estudantes a terem mais organização e controle sobre suas responsabilidades escolares, evitando o esquecimento de atividades e ajudando no acompanhamento das tarefas do dia a dia.

## Funcionalidades

- **Cadastrar matérias:** adicionar as matérias escolares ao sistema.
- **Visualizar matérias:** consultar todas as matérias cadastradas.
- **Adicionar atividades:** registrar tarefas e atividades vinculadas a uma matéria.
- **Visualizar atividades:** consultar as atividades cadastradas e seus status.
- **Concluir atividades:** marcar tarefas escolares como concluídas.

## Tecnologias utilizadas

- JavaScript
- Node.js
- Prompt-Sync

## Como instalar e executar

**1.** Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

**2.** Entre na pasta do projeto:

```bash
cd StudyTrack
```

**3.** Instale as dependências:

```bash
npm install
```

**4.** Execute o programa:

```bash
node js/studytrack.js
```
